# colibre-skirt
This repository contains a tutorial (`tutorial.ipynb`) for postprocessing a single galaxy from the [COLIBRE](https://colibre.strw.leidenuniv.nl/) simulations with the [SKIRT](https://skirt.ugent.be/root/_home.html) 3D dust radiative transfer code, producing its spatially integrated spectrum from the FUV to the FIR.

## Contents
- `tutorial.ipynb`: the tutorial notebook, covering the galaxy selection, the extraction of the particle data, and the SKIRT configuration.
- `template_v6.0.ski`: the SKIRT configuration file.
- `L025_m6_Thermal_snap0127_ID1694.hdf5`: the SKIRT input file for the example galaxy, as generated by the notebook.
- `environment.yml`: the conda environment used to run the notebook on cosma8.

## Pipeline version (v6)
The setup largely follows the COLIBRE-SKIRT pipeline described in [Gebek et al. 2026](https://scixplorer.org/abs/2026arXiv260714901G/abstract), with these main changes:
- SKIRT 9 → SKIRT 10 (beta).
- Dust-free TODDLERS v2 → dust-attenuated TODDLERS v2-varDTM templates for the star-forming regions, with the subgrid dust mass subtracted from the diffuse COLIBRE dust so that the total dust mass is conserved.
- SKIRT input stored in a single HDF5 file per galaxy instead of separate text files.

The previous version of the pipeline (v5, SKIRT 9 with `template_v5.0.ski`) is available under the `v5` tag of this repository.

## Access to COLIBRE data
To access the COLIBRE data, you will need an account on the cosma8 machine. The tutorial notebook illustrates how to interface with the COLIBRE data using [swiftsimio](https://github.com/SWIFTSIM/swiftsimio) and [swiftgalaxy](https://github.com/SWIFTSIM/swiftgalaxy), and how to derive the necessary SKIRT input. To recreate the Python environment used for the notebook:
```bash
conda env create -f environment.yml
conda activate COLIBRE-v6
```

## SKIRT setup
This pipeline requires the SKIRT 10 beta version, built with HDF5 support, and the `BPASS` and `TODDLERS_VariableDust` resource packs. Detailed installation instructions are given at the start of the tutorial notebook. To run SKIRT on the example galaxy:
```bash
skirt -i ./L025_m6_Thermal_snap0127_ID1694.hdf5 template_v6.0.ski
```

## Postprocessing more galaxies
This tutorial covers the basic COLIBRE-SKIRT workflow for a single galaxy. To postprocess more galaxies, an efficient workflow will require iterating over galaxies and using HPC systems. The `hpc_workflow_anna` branch of this repository contains such an example workflow (based on the v5 pipeline).
